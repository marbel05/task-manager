# Definition of Done

A change is considered done when:

- [ ] The implementation meets the task requirements.
- [ ] The architecture follows `standards/spec.md`.
- [ ] Input validation and error handling are implemented where required.
- [ ] Relevant unit and integration tests are added or updated.
- [ ] All automated tests pass.
- [ ] `npm run format:check` passes.
- [ ] `npm run lint` reports no errors.
- [ ] `npm run build` passes.
- [ ] `npm run check` passes.
- [ ] Documentation is updated when behavior or architecture changes.
- [ ] No database files, secrets, or `node_modules` are committed.
- [ ] The change is reviewed through a Pull Request before merging.
- [ ] CI passes before merging into the main branch.
